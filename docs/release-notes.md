# 发布说明（R20.AC-5）

## 0.1.0 可自用版本（M1～M8，2026-11-27）

这是给自己试用的早期版本。全部功能都已在开发机上通过单元测试和本地模拟模型服务的界面实测；**还没有在其他 Windows 机器上做实机验证，也还没有接真实模型服务测试**。

### 安装

- `DeskNest-0.1.0-setup.exe`：安装版，可以选择安装位置；不需要管理员权限。
- `DeskNest-0.1.0-win.zip`：解压版，解压后运行 `DeskNest.exe`。
- 安装包没有数字签名，Windows 可能提示“未知发布者”（D-12）。
- 数据保存在 `%APPDATA%\desk-nest`，不在安装目录。覆盖安装会保留全部数据；卸载时会询问是否同时删除数据，默认保留。

### 已有的功能

- **宠物**：透明窗口、拖动、触碰反馈、右键菜单、松手贴边、外部全屏时自动隐藏、三档尺寸、降低动态效果、托盘、记住位置。
- **小窝**：笔记（回收站 7 天）、待办（记录进展、关联事项）、事项、提醒、信箱、沙漏（专注）、中文搜索、设置。
- **提醒**：表单或一句话创建一次性提醒；到期进信箱并弹出气泡；推迟、改期、取消；安静模式；错过的提醒汇总提示。
- **对话**：接入 OpenAI 兼容服务（DeepSeek、通义千问、Kimi、智谱、Ollama 等）；密钥系统加密；没配置或断网时本地功能照常可用。
- **一句话操作**：创建提醒、记笔记、设置称呼和说话方式、记住事项和进展、记住简短的信息、约定跟进、忘记；结果以本地卡片显示，可以撤销或修改。
- **记忆与跟进**：约好的时间按最新进展来问；事情完成后跟进自动取消；纠正和忘记后旧内容不再出现。
- **专注**：按真实经过的时间计时，睡眠和锁屏期间继续；结束后由你选择完成待办、记录进展或再来一轮。
- **数据**：导出全部数据（不含密钥）、从导出文件恢复、清除所有数据、聊天记录保留期限和删除；数据库打不开时可以从备份恢复。

- 系统级计划通知：应用退出后不会提醒（D-03）。
- 安装包签名、自动更新（D-12）。
- 一周核心场景验收（需求 §9.3）、在其他机器上的实机验证（R20.AC-2）。

### 已知限制

- 应用没有运行时不会提醒；开机启动默认关闭，首次创建提醒时会提示开启。
- 对话还不能查询、修改、改期或取消已有的记录，这些请用结果卡片上的按钮或小窝。
- 记忆按中文字面匹配，同义说法（“面试”和“求职”）可能匹配不到；这时宠物会说不记得。
- 纠正或忘记之后会截断较早的聊天历史，接下来几轮的连贯性会差一点。
- 没说“记住”“问问我”时，宠物不会直接保存或安排，而是请你确认一下。
- 是否支持工具调用，要等模型服务拒绝时才知道。
- 已经发送给模型服务的聊天内容不受本机删除控制。
- 专注统计只有单次结果，没有统计页面（D-07）。
