## 已知限制（不算失败）

- 改称呼后，旧称呼仍留在最近 12 条聊天记录里，模型偶尔可能沿用；系统提示词说明以当前称呼为准，彻底截断在 M7。
- 不能用对话修改、改期、取消或查询已有记录，也不能创建待办；改期和取消用卡片按钮。
- 是否支持工具调用只在服务返回 HTTP 400 时才知道（“测试连接”还不检测这一项）。
- 服务没有统一返回 token 用量，评估报告用字符数近似。
- 没说上午下午的钟点按固定规则理解（见 TD §8.1），卡片显示完整时刻，可以立即修改。
